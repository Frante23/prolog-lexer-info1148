\subsection{Evidencia de ejecución}

La siguiente secuencia reproduce la validación y genera el PDF actualizado. Las cifras se obtienen de la ejecución de las pruebas y del corpus; la duración depende del equipo.

\begin{lstlisting}[style=terminal]
python scripts/validate.py
python scripts/build_report.py
python -m src.cli corpus/programa_valido.pl --json
python -m src.cli corpus/programa_con_errores.pl --json
\end{lstlisting}

El informe se puede compilar con pdfLaTeX, XeLaTeX o Tectonic. Los dos primeros motores realizan al menos dos pasadas; Tectonic gestiona sus propias repeticiones. Se comprueba que no queden referencias sin resolver. Se utiliza Latin Modern sin depender del registro de fuentes del sistema ni de Perl. La opción \texttt{--publish} valida las pruebas antes de compilar y solo actualiza \path{informe/main.pdf} si ambos pasos terminan correctamente. La copia para la plataforma es \path{informe/Tarea_JefeGrupo_JoseJimenez.pdf}.
