\subsection{Evidencia de ejecución}

La siguiente secuencia reproduce la validación y genera el PDF actualizado. Las cifras se obtienen de la ejecución de las pruebas y del corpus; la duración depende del equipo.

\begin{lstlisting}[style=terminal]
python scripts/validate.py
python scripts/build_report.py
python -m src.cli corpus/programa_valido.pl --json
python -m src.cli corpus/programa_con_errores.pl --json
\end{lstlisting}
